The problem

One agent is easy. Four is a scheduling problem.

They run asynchronously, they all stop to ask you something eventually, and terminal tabs hide the one that is blocked. So you cycle through tabs looking for the agent that went quiet for the wrong reason.

Soprano is built around the question you actually have all day: which agent needs me right now? Panes answer it themselves.

  • Starting

    The launcher is up, the agent has not reported in yet.

  • Working

    A turn is in flight. Leave it alone.

  • Ready

    Idle and waiting for a prompt.

  • Needs input

    A question or a permission prompt. This is the one you came for.

  • Error

    The turn failed. The pane keeps the state until you look.

  • Stopped

    The process exited. The layout stays where you left it.

What you get

A real terminal, arranged the way you think.

Notifications that name the place

Subtitled window ▸ pane. Clicking one activates Soprano and focuses that exact tab — no hunting.

libghostty surfaces

Every pane is a real GPU-rendered terminal hosted in AppKit. No Electron, no web view, no reimplemented VT parser.

Splits on a prefix ⌃A

tmux-style chords for splitting and resizing, plus ⌃H/J/K/L to move between panes with no prefix at all.

Depth ⌃A I

Any pane opens a private workspace on the window's z-axis, so one pane becomes a whole layout while its siblings keep running.

A browser your agents drive ⌘B

A WebKit pane splits off to the right. From inside any terminal, "$SOPRANO_BIN" browser click @e1 works.

Layouts that come back

The last workspace restores on launch, and ⇧⌘S saves named sessions you can return to.

Install

Build it from source.

Soprano links libghostty statically, so the first build compiles it once. After that you only repeat it when the ghostty submodule moves.

Fresh clone to installed app
# 1 · Toolchain. Homebrew Swift is required — the system CLT Swift has broken SPM.
$ brew install swift zig
$ xcodebuild -downloadComponent MetalToolchain

# 2 · Clone with the ghostty submodule
$ git clone --recurse-submodules https://github.com/frknue/soprano.git
$ cd soprano

# 3 · Build libghostty once (a few minutes)
$ ./scripts/build-ghostty.sh

# 4 · Build the release app into /Applications
$ ./install.sh

Requirements: macOS 14 Sonoma or newer · full Xcode with the Metal Toolchain (Command Line Tools alone cannot build libghostty) · Homebrew Swift 6.2+ · Zig 0.15.2+.
